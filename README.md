# Dhanush — AI Portfolio

Bilingual personal portfolio (German / English) built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Portfolio content

- About, professional experience and education
- Four selected AI projects: E-Invoice Copilot, Version-Aware Docs Assistant, Verified-RCA, llm-replay
- German / English language toggle
- GitHub profile: https://github.com/Dhanush-pv

Project cards show a description, 4-5 highlight bullets and technology tags.
